الترقية لـ (Blaze): قراءات وكتابات لا نهائية وتوسيع فوري.
السعر: الدفع حسب الاستهلاك (Pay as you go) يبدأ من $0.

Cloudflare Workers Paid

تشغيل الـ API وفصل النطاقات الفرعية (Subdomains) وإرسال إشعارات التيليجرام.

الحد المجاني: 100,000 طلب يومياً (100k requests/day).
الترقية المدفوعة: 10 ملايين طلب شهرياً مع وقت معالجة مفتوح 30s.
السعر: 5$ / شهرياً (يشمل 10M طلب).

📦 تخزين صور المنتجات

Cloudflare R2 Object Storage

تخزين سحابي عالي السرعة لصور الكتالوج دون أي تكاليف نقل بيانات (Zero Egress Fees).

الحد المجاني: 10 جيجابايت تخزين مجاني + باندويث لا نهائي.
الترقية: سعة غير محدودة لملايين صور المنتجات.
السعر: $0.015 لكل جيجابايت إضافي شهرياً.

Cloudflare Pro Plan (Domain & WAF)

ضغط الصور التلقائي (Polish/WebP)، جدار حماية WAF لمنع هجمات الـ DDoS، وتسريع كاش الشرق الأوسط.

الخطة المجانية: DNS وSSL وتوزيع كاش قياسي.
خطة Pro: تحويل الصور لـ WebP وتصغير حجم المتجر بنسبة 60%.
السعر: 20$ - 25$ / شهرياً لكل نطاق رسمي.
