النطاق الفرعي المجاني

رابط سريع تلقائي على نطاق المنصة نفسها، مثال: pharmacy-name.yoursite.com. يتم تفعيله فوراً بلا أي إعدادات DNS إضافية.

🔗 ضمن اشتراكك الحالي

رابط فرعي من دومينك الخاص

رابط فرعي مخصص تحت دومين رئيسي تملكه أنت مسبقاً، مثال: pharmacy-name.mainbrand.com. يولّد سجل CNAME تلقائياً عبر Cloudflare API عند توفر بيانات الاعتماد.

👑 ~10$-15$ سنوياً

دومين خاص مستقل بالكامل

ربط اسم نطاق مستقل يملكه الصيدلي بالكامل، مثال: www.al-qutn-pharmacy.com، مع إرشادات DNS كاملة وأداة تحقق من الاتصال.

Google Firebase (Blaze Plan)

السعر: الدفع حسب الاستهلاك يبدأ من 0.06$ لكل 100k قراءة إضافية.

Cloudflare Workers Paid

تشغيل الـ API، عزل النطاقات الفرعية، الكاش السحابي 60 دقيقة، وإعادة احتساب الأسعار.

الباقة الحالية (Free): 100,000 طلب يومياً (مجاناً).
باقة الترقية (Paid): 10 ملايين طلب شهرياً مع وقت معالجة 30s.

📦 تخزين الصور والكتالوج

Cloudflare R2 Object Storage

استضافة صور الكتالوج والبانرات بسرعة فائقة وبدون أي رسوم لنقل البيانات (Zero Egress Fees).

الباقة الحالية (Free): 10 جيجابايت تخزين مجاني + 10M قراءة شهرياً.
باقة الترقية: سعة غير محدودة لملايين صور المنتجات.
السعر: 0.015$ لكل 1 جيجابايت إضافي شهرياً.

Cloudflare Pro Plan (Domain & WAF)

تسريع كاش العراق والشرق الأوسط، ضغط الصور التلقائي لـ WebP، وحماية WAF ضد هجمات الـ DDoS.

الباقة الحالية (Free): DNS وإدارة شهادات SSL وتوزيع قياسي.
باقة الترقية (Pro): تحويل الصور تلقائياً لـ WebP وتسريع التصفح 60%.
السعر: 20$ - 25$ شهرياً للنطاق الرسمي.
